Authentication

All API requests require an API key passed in the Authorization header. Keys are issued to verified researchers, NGOs, and academics. Sentinel-tier users and above can request a key from their profile page.

Request header
Authorization: Bearer sv_live_xxxxxxxxxxxxxxxxxxxx
Example — curl
curl
Python
JavaScript
curl -X GET "https://api.scamvault.org/v1/reports" \ -H "Authorization: Bearer sv_live_xxxxxxxxxxxxxxxxxxxx" \ -H "Accept: application/json"
import requests headers = {"Authorization": "Bearer sv_live_xxxxxxxxxxxxxxxxxxxx"} r = requests.get("https://api.scamvault.org/v1/reports", headers=headers) data = r.json()
const res = await fetch("https://api.scamvault.org/v1/reports", { headers: { "Authorization": "Bearer sv_live_xxxxxxxxxxxxxxxxxxxx" } }); const data = await res.json();

GET /reports List published reports
Query parameters
Parameter Type Required Description
type string optional Filter by scam type. One of: phishing_email, smishing, investment_fraud, romance_scam, bec, tech_support, crypto_fraud
country string optional ISO 3166-1 alpha-2 country code. e.g. GB, NG, GH
severity integer optional Minimum severity (1–5). Returns reports at this level and above
from datetime optional ISO 8601 start date. e.g. 2025-01-01T00:00:00Z
to datetime optional ISO 8601 end date
is_novel boolean optional If true, returns only novel/new campaign reports
limit integer optional Results per page. Default 50, max 200
cursor string optional Pagination cursor from previous response next_cursor field
Example response
{ "data": [ { "id": "rpt_01hwx3k...", "type": "phishing_email", "severity": 4, "country": "NG", "summary": "Fake Access Bank email harvesting credentials...", "tags": ["bank_impersonation", "credential_harvest"], "is_novel": false, "confirm_count": 23, "published_at": "2025-05-08T09:14:22Z" } ], "meta": { "total": 14382, "limit": 50, "next_cursor": "eyJpZCI6..." } }

GET /indicators Search extracted IOCs
Query parameters
Parameter Type Required Description
type string optional One of: domain, ip_address, email_address, phone_number, url
value string optional Exact or partial match. e.g. value=accessbank
limit integer optional Default 100, max 500
GET /campaigns Clustered scam campaign groups

Campaigns are automatically clustered groups of similar reports. A campaign with a high report_count indicates an active, ongoing threat.

Example response
{ "id": "cmp_09kqz...", "name": "Access Bank credential harvest — May 2025", "type": "phishing_email", "report_count": 87, "first_seen": "2025-05-01T00:00:00Z", "last_seen": "2025-05-08T11:30:00Z" }
GET /export/stix STIX 2.1 bundle — Elite Sentinel+

Returns a STIX 2.1 compliant bundle of indicators and threat actors. Compatible with any TAXII-enabled SIEM or threat intel platform.

Example response
{ "type": "bundle", "id": "bundle--f9a8...", "spec_version": "2.1", "objects": [ { "type": "indicator", "id": "indicator--3b4c...", "name": "Phishing domain — accessbank-secure.net", "pattern": "[domain-name:value = 'accessbank-secure.net']", "pattern_type": "stix", "valid_from": "2025-05-01T00:00:00Z" } ] }
